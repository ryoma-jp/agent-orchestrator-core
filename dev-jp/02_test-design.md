# テスト設計書

## 1. 目的と対象

本書は、現行のPythonテストが保証する入力契約・認証境界・秘密情報の取り扱い・モデル出力フォールバックを定義する。対象は `backend/tests/test_contracts.py` の11ケースと、テスト収集前の設定を行う `backend/tests/conftest.py` である。

現行テストはユニット/コンポーネントテストを中心とし、PostgreSQL、Vault、OpenAI APIへの実接続やUIのブラウザーE2Eは行わない。

## 2. 実行方法

Python 3.10以上と開発依存を用意し、リポジトリルートから実行する。

```sh
python -m pip install -e ".[dev]"
python -m pytest -q
```

pytestの探索先は `backend/tests`、asyncテストは `pytest-asyncio` のauto modeで実行する。現行テストはDB接続を発生させないため、PostgreSQLやDockerの起動は不要。

## 3. テストケース

| ID | テスト対象 | 設計意図・確認内容 |
|---|---|---|
| UT-001 | タスク作成入力 | 空でないタスク指示が `TaskCreate` で受理されることを確認する。 |
| UT-002 | タスク作成入力 | 空のタスク指示を `TaskCreate` が拒否することを確認する。 |
| UT-003 | 会話入力 | 空でない追加メッセージが `MessageCreate` で受理されることを確認する。 |
| UT-004 | 計画依存関係 | 先行タスクに依存する有効なサブタスク計画が受理されることを確認する。 |
| UT-005 | 計画依存関係 | サブタスク間の循環依存を `TaskPlan` が拒否することを確認する。 |
| UT-006 | パスワード保護 | パスワードが平文保存されず、正しい値だけが検証に成功することを確認する。 |
| UT-007 | 入力エラー応答 | ログイン要求の入力検証失敗が汎用422応答となり、送信したパスワードが応答本文へ含まれないことを確認する。 |
| UT-008 | Bearer認証 | 保存済みキーのハッシュに一致するBearerキーが、対応する有効ユーザーを認証することを確認する。 |
| UT-009 | Bearer認証 | 未登録キーがHTTP 401で拒否されることを確認する。 |
| UT-010 | 更新要求のCSRF境界 | Bearer認証要求ではブラウザー用CSRF Cookieを要求しないことを確認する。 |
| UT-011 | OpenAI出力互換性 | Structured Outputsが未対応の応答を受けた後、通常JSONへ切り替え、同一スキーマで解析・検証できることを確認する。 |

## 4. テスト用依存の置き換え

- `conftest.py` は `MANAGER_MODEL` と `WORKER_MODEL` にテスト用既定値を設定し、アプリ設定の読み込みに必要な値を補う。実モデルへの呼び出しは行わない。
- Bearer認証ケースは `FakeAccessKeySession` を使い、DB検索結果を制御する。PostgreSQLのSQL実行や永続化は検証しない。
- 入力エラー応答は `httpx.ASGITransport` でFastAPIアプリ内に送信する。外部HTTPサーバーやログイン済みセッションは必要としない。
- OpenAIフォールバックケースはSDKクライアントとVaultキー読取関数をモックする。最初のStructured Outputs拒否と、次のJSON応答を決定的に再現する。

## 5. 現行の対象外

以下は現行テストでは保証しない。PostgreSQLを使う統合テスト、Workerの並行/リース試験、Vault・OpenAI実接続試験、ブラウザーE2Eとして別途追加する。

- DBトランザクションによるタスク・会話・イベント・ジョブの原子性、所有者境界、マイグレーションの実適用
- セッション発行/期限切れ/ログアウト、Cookie認証時のCSRF拒否、アクセスキーの発行・ローテーション・永続化
- SSEのLast-Event-ID再送、Worker再起動・リース回収、複数Worker間の排他、追加指示時の再計画
- キャンセルと完了の競合、終端タスク削除、管理者API権限、Vault秘密値の保存/非再表示
- UIのログイン、フォーム操作、レスポンシブ表示、APIとの結合
- Sandbox、承認/要確認、プライベートスキル、RAG、成果物、コンテキスト要約、利用量/コスト
